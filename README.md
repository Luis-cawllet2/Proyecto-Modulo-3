## Descripción del proyecto
Es un juego en Python donde el programa elige un número al azar entre 1 y 100 y el usuario tiene que adivinarlo. Después de cada intento el programa dice si el número secreto es mayor o menor. El juego termina cuando el usuario acierta o se le acaban los 7 intentos.

El programa usa:
- `input()` para pedir el número al usuario.
- `while` para repetir los intentos hasta acertar o quedarse sin intentos.
- `if`, `elif` y `else` para dar las pistas "mayor" o "menor" y para mostrar si ganó o perdió.
- `print()` con f-strings para mostrar los mensajes.
- La librería `random` para generar el número aleatorio.

## Cómo ejecutarlo
```
python main.py
```
